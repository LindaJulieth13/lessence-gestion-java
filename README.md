# Sistema de Gestión de Perfumes L'ESSENCE

## Descripción
Aplicación desarrollada en Java para gestionar el inventario
de perfumes de la tienda L'ESSENCE mediante una conexión
a una base de datos MySQL utilizando JDBC.

## Tecnologías utilizadas
- Java
- MySQL
- MySQL Connector/J
- JDBC
- Visual Studio Code

## Funcionalidades
- Registrar perfumes.
- Consultar perfumes.
- Actualizar información de perfumes.
- Eliminar perfumes.

## Base de datos
Nombre: lessence_java

Tabla: perfumes

Campos:
- id
- nombre
- marca
- categoria
- precio
- stock

## Estructura del proyecto
- src/conexion: conexión con MySQL.
- src/modelo: modelo de perfumes.
- src/dao: operaciones CRUD.
- evidencias: capturas de las pruebas.
- lib: controlador JDBC.
